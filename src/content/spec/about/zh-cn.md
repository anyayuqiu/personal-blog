## 个人简介

本人熊宇，长安大学软件专硕研二在读，本科毕业于西安工业大学软件工程专业，研究生阶段从事 **VLM（视觉语言模型）机理可解释性** 研究，关注多模态大模型内部表征、注意力机制、神经元行为与可解释性分析方法。

技术方向以 **Java 工程开发、LLM / Agent 应用开发、多模态大模型研究** 为主，熟悉 Java、面向对象设计、常用设计模式与数据结构，了解大模型推理、Prompt 工程、RAG、Agent 工具调用等方向。

也具备 C/C++、Linux、RTOS 驱动开发等底层工程基础，大三的时候曾在华勤技术股份有限公司担任驱动开发工程师实习生，具备实际的工程落地与调试能力。（我很清楚写这段实习经历对找工作对与我要找的工作方向没有帮助，但我想表明我可以承担很多事情）

## 技术栈

**Java / 后端**

- 语言与基础：Java、面向对象设计、常用设计模式（单例、工厂、抽象工厂等）、数据结构与算法（链表、栈、队列等）
- 框架与工程：Spring Boot、Spring MVC、MyBatis-Plus、Maven 多模块开发业务接口
- 数据与中间件：MySQL 常用 SQL、事务及索引基础；Redis 登录令牌、验证码与限流；MinIO 图片存储与访问配置
- 工程基础：Git、Linux、Docker Compose、Caddy；C/C++、多线程；具备模型 API 接入、应用联调、云部署与底层接口调试经验

**大模型 / Agent**

- LLM 基础：Prompt 工程、上下文管理、工具调用、OpenAI 兼容接口
- 框架与能力：LangChain4j、工具调用、对话记忆、SSE 流式响应
- RAG：检索增强生成、向量检索、知识库构建、RAG 基本能力
- Agent：任务规划、工具调用、多轮对话、工作流编排
- 多模态大模型：VLM 结构、视觉-语言对齐、注意力机制、视觉编码、M-RoPE
- 可解释性：内部表征分析、注意力可视化、Attention Rollout、Head 输出消融、KL 分析、神经元行为分析

**研究 / 实验**

- 编程与框架：Python、PyTorch、Transformers
- 模型实验：理解 Transformer、GQA、KV Cache、视觉编码与 M-RoPE；开展推理、结构修改和评估
- 可解释性与压缩：Attention Rollout、Head 输出消融、KL 分析、Q/O 结构化剪枝、视觉 Token / Block 选择；区分相关性、因果干预和部署收益
- 训练与评估：LoRA、Answer-only SFT、VQAv2 共识评分、层匹配随机对照、配对及图像簇 Bootstrap；具备训练 / 评估样本隔离经验
- 研究方向：VLM 机理可解释性研究
